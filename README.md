# OTB1
OTB1 (Outside The Box) is a modding project for the VTech InnoTV. It explores the console’s software, firmware, storage, and security to see what can be done beyond the original system.
Its not being made because I don't know how to code but I think it is a good idea 

## Server safety

This project does not hack, attack, disrupt, or access VTech servers. Any server-related research must use public information, local test services, or systems where explicit permission has been given.













The OS: It runs a heavily modified, locked-down version of Android (which means standard Android exploitation techniques might apply). 








The Goal: To document the InnoTV, preserve its software and storage, and experiment only on hardware and local services that we own or have permission to test, and eventually run custom homebrew or emulators. 






The Appeal: Emphasize that it's an untouched, obscure console. Many hackers love the challenge of being the "first" to break a specific system.
